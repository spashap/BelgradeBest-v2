Admin analytics: Today range, day-by-day traffic chart, Search Console follows the range

Range selector gains "Today" (GA4 today vs yesterday, hour by hour) next to
7d / 28d / 90d. The two sparklines are replaced by a three-row trend chart
sharing one x-axis: visitors, pageviews, and a diverging change row
(visitors vs the previous day; vs the same hour yesterday on Today). Hover
any column for the exact numbers; a collapsed table view lists every point.

Search Console tables now take the selected range instead of a fixed 28
days. Windows end at the latest day Search Console has data for (today - 2)
and the heading shows the actual dates; Today shows the latest single day.

lib/admin/analytics.ts: ga4Overview(days=1) = today/yesterday with an hourly
series (keepEmptyRows); daily series fetches one extra baseline day so the
first day has a delta; TrendPoint carries prevUsers/prevViews. gscQuery()
takes days and returns the window it queried.
