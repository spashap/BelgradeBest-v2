Language suggestion bar by browser language (not a redirect)

A visitor whose browser prefers German, Slovak, Czech or English, on a page
that exists in that language, sees one dismissible strip under the header,
written in that language ("Diese Seite gibt es auch auf Deutsch. Auf
Deutsch lesen ->").

- components/LangSuggest.astro + c-langbar in globals.css; BaseLayout
  renders it. Bars ship hidden, so crawlers see nothing new.
- It reads the browser's languages in order and stops at the page's own
  language, so English-first readers on English pages see nothing.
- While shown, the matching in-content language note is hidden (no double
  invitation); closing brings it back and is remembered.
- GA4 events lang_suggest_show / click / dismiss.
- CLAUDE.md documents it. Change log BB-CHG-0065.
