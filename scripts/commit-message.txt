Admin Analytics: pick the date range (presets + custom from/to)

/admin/analytics showed fixed windows (Today / 7 / 28 / 90 days). It now
takes any range, kept in the URL so a view can be bookmarked:
/admin/analytics?from=YYYY-MM-DD&to=YYYY-MM-DD

- Presets: Today, 7 days, 28 days, 90 days, This month, Last month.
  "Last N days" ends yesterday, like GA4's own presets and the Growth API,
  so the numbers match across tools. Plus two date inputs and Apply.
- lib/admin/range.ts parses and validates: a start after the end, a future
  end or a non-date falls back to the last 28 days with a notice; a start
  before the GA4 data (DATA_START 2026-06-01) is moved to that day. Days are
  Belgrade calendar days. Old ?days= links still work.
- The same from/to reaches every report on the tab, each compared with the
  equally long period before: GA4 overview, trend and engagement cuts,
  Search Console (cut at its ~2-day lag), Bing (history cached once, cut per
  range), affiliate clicks and CJ earnings.
- A one-day range shows hours against the day before (as Today did).
- The day-by-day trend is built per calendar day, so a day GA4 leaves out
  shows as 0 instead of shifting the series.
- CJ earnings are queried in 31-day slices, so ranges over 31 days are
  complete (on /admin/affiliates too: 90 days used to stop at 31).
- Date inputs styled in AdminLayout with the admin tokens.
- Tests: tests/admin/range.test.ts (npm test runs them). CLAUDE.md notes
  the range.

Admin only; the public site is unchanged, so no growth change-log entry.
