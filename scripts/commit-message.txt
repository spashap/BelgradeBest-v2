== 2. IndexNow key file fix ==

Every IndexNow submission for belgradebest.com has been rejected with
403 UserForbiddedToAccessSite, against both api.indexnow.org and
www.bing.com/indexnow. The site itself is fine — verified in Bing Webmaster
Tools and crawled daily.

Cause: public/14ec77dc669e4a48947348a73e9ee9b7.txt ended with a 0x0a byte, so
the served key file was "14ec...9b7\n" rather than the exact key. IndexNow
compares the file body to the submitted key byte-for-byte and treats the
mismatch as a failed verification. The file now holds the 32 hex chars and
nothing else, and .gitattributes pins that one path as `binary` so the repo-wide
`* text=auto eol=lf` normalization can never re-introduce a line ending.

This unblocks the build-time ping in astro.config.mjs (indexNow() in
astro:build:done), which has been silently failing on every production deploy
since it was added.
