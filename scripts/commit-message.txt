Strip known bots from analytics: no GA4 tag for headless browsers, filtered from every report

Singapore topped the admin analytics. It is a bot: 139 sessions / 139 users
in 28 days, all Direct, exactly 1 page, 0 s engagement, at screen sizes no
real device reports (1280x1200, 1366x1366). GA4's built-in bot filter misses
it. It inflated users by ~47% and pulled engagement rate from 49% to 36%.

- src/lib/bot-traffic.ts: the one list of bot signatures + the GA4 filter.
- Analytics.astro: the tag is not loaded when navigator.webdriver is set or
  the screen size is on the list, so new bot hits never reach GA4.
- lib/admin/analytics.ts + lib/growth/runners.ts: every GA4 report excludes
  those screen sizes, so the history is clean too (28d: 440 -> 300 users).
- growth_changes.jsonl: BB-CHG-0020. Expect a step down in raw GA4 users;
  it is not a traffic loss.
